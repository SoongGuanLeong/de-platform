# Delivery is validated artefacts and a runbook, not a GitOps controller

**Status:** accepted

No cloud arm is applied outside a priced demo window, so the platform has no standing environment to reconcile against. Delivery is therefore the **deployable artefact**: the commit on `main` whose required check is green and whose `deployment/` tree renders and pins its inputs, with a `demo-<YYYY-MM-DD>` tag naming the commit a priced window is run from. The delivery mechanism inside that window is the runbook, which applies the minimal arm with OpenTofu and installs the charts with `helm install` or `helm upgrade`. **No GitOps controller is adopted.** The reasoning is arithmetic rather than taste. A controller's only possible target is the cluster inside a priced, torn-down demo window, so the platform would carry a component, or a capability plus a prerequisite, exercised for a few hours and nowhere else. Self-hosted Argo CD would be a twentieth component with **no local evidence path at all**, because it needs a cluster and this host cannot run one, which is the same failure this effort already names for the old repository's Trino: wired and never queried, and therefore proving nothing. Its footprint also cannot be cited honestly, because Argo CD publishes no recommended resource requests or limits, its manifests set none, and the numbers in its Helm values that resemble recommendations are VPA `minAllowed` examples, so any sizing would be our invention. Managed Argo CD is real and cheap in cash but not in surface: EKS Capabilities is **$0.029108 per capability-hour plus $0.001452 per Argo CD Application hour in ap-southeast-5**, where an Application hour is counted per Application per target-cluster deployment and each ApplicationSet-generated instance counts as one Application, so one capability and one Application for a 6-hour demo is **$0.174648 + $0.008712 = $0.18336**, which is 9.1% on the two-node minimal arm's $2.02 and 7.0% on the three-node demo's $2.61. It is not a cluster add-on, and it hard-requires **AWS Identity Center**, which does not support local users, plus an IAM capability role and per-target-cluster RBAC because the auto-created access entry cannot deploy. It is also a managed service the platform operates, which contradicts [ADR-0027](0027-self-host-what-the-platform-operates.md)'s self-host posture.

## Considered options

- **Self-hosted Argo CD.** Rejected: a twentieth component with no local evidence path, an unsourceable footprint, and no requirement that names it. The mission's Kubernetes section asks for deployments, services, config, secrets, health checks, resource limits, persistent storage, Helm packaging, rolling updates and failure or restart behaviour. The charts declare every one of them and the runbook is where they are exercised; the only item on that list a controller would add is continuous reconciliation, which is not on it.
- **Managed Argo CD through EKS Capabilities.** Rejected: it adds AWS Identity Center as a mandatory prerequisite for a surface the platform otherwise never touches, it contradicts ADR-0027's self-host line, and it buys a demonstration the mission does not ask for. It remains the option to take **if** this decision is ever reversed, because it adds no component to the count.
- **A controller that runs locally against a kind or k3s cluster.** Rejected: it would put a Kubernetes cluster inside the same 7 to 8 GB the path profiles already struggle to fit, and it would evidence a local cluster rather than the EKS shape.

## Consequences

The loss is a reconciliation demonstration, recorded as an **out-of-scope mechanism** rather than a gap, with one trigger: **if the cloud arm ever becomes a long-lived environment rather than a demo, this decision is reopened**, because a controller then has a target that outlives a window. The gain is that the delivery path adds nothing to the nineteen components, needs no AWS credential in CI, and keeps the demo's only moving parts the runbook and the charts. ECR's role in the cloud arm is narrowed by this decision and is stated in [ADR-0034](0034-the-one-built-image-is-published-to-ghcr.md): it is authored and no run uses it.
