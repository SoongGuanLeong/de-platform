# Self-host what the platform operates, and buy only the primitives

**Status:** accepted

The cloud topology self-hosts Kafka, Flink, ClickHouse, Polaris, Dagster, Apicurio, Marquez and the observability stack on EKS, and goes AWS-managed only for the primitives and the two services the posting names as AWS: S3 for object storage and RDS for PostgreSQL. The test that draws the line is not price, it is what the artefact proves. Each managed alternative would replace the thing the platform exists to demonstrate - KRaft retention and the replayable log, the Flink upsert sink with its keyed LSN operator, MergeTree part management, Polaris's prefix-scoped credential vending - and a managed substitute cannot be swapped in for the vendor-neutrality drill, because there would be nothing left to swap. The primitives are the opposite case: nobody demonstrates object storage by running Ceph, and S3 is SeaweedFS's cloud form rather than an addition. This is also the cheaper side of the line at the entry point, which is a consequence rather than the reason: MSK Serverless is $0.75 per cluster-hour in us-east-1 against $0.0912 for the entry provisioned cluster (two brokers, since MSK Provisioned requires at least two subnets in two AZs), and both sit on top of compute the design already pays for. Self-hosting Kafka on nodes the cluster already runs is therefore both the demonstrable option and the cheaper one.

## Considered options

- **Amazon MSK, Serverless or Provisioned.** Rejected: it replaces the replayable log, the time-bounded CDC retention (ADR-0018) and the ordering work the streaming claims rest on, and it is priced above self-hosting on the same nodes. The comparison is recorded in [research 21](../research/21-aws-pricing-snapshot.md).
- **Managed Service for Apache Flink.** Rejected: the Flink upsert sink and the keyed stateful operator that holds the maximum `source.lsn` per key (ADR-0013) are the artefact. A managed runtime would leave the platform demonstrating a configuration rather than a mechanism.
- **ClickHouse Cloud.** Rejected on the same ground: MergeTree part management, projections and the serving-copy layout are the artefact, and the licence audit in [research 14](../research/14-licence-and-cost-audit.md) covered licence terms rather than managed-service prices, so this rejection rests on the artefact argument and not on a price comparison.
- **Glue Data Catalog as the Iceberg REST catalog.** Rejected: it would delete Polaris from the cloud topology, which is the opposite of what M9, M10 and ADR-0010 exist to show. Polaris's prefix-scoped credential vending is the one governance control the platform has measured against a real STS endpoint, and Glue has no equivalent that was demonstrated.
- **Amazon Managed Prometheus and Amazon Managed Grafana.** Rejected: dashboards as code in Git and a genuinely unprompted alert are the evidence, and Grafana stays unmodified under AGPL-3.0, which a managed offering does not change.
- **Aurora Serverless or a self-hosted PostgreSQL on EKS.** Rejected: RDS is the posting's own named service, and `db.t4g.micro` is free-plan-eligible, so RDS is not what makes a zero-dollar deployment impossible - the EKS control plane is. Self-hosting the database would remove a posting-named managed service without buying anything.
- **Managed Kubernetes (EKS) with self-hosted everything else.** Taken, with the control plane's opt-in charges refused: Provisioned Control Plane, EKS Auto Mode, EKS Capabilities and extended support are each recorded as rejected in [the cloud architecture](../cloud-architecture.md).

## Consequences

The platform owns the operational burden for eight stateful systems, which is the point rather than a cost: the posting asks for someone who will own, operate and harden them. High availability becomes the platform's own responsibility, so the reference arm's replication is declared explicitly - three Kafka brokers, two ClickHouse replicas, two Polaris replicas - and what is deliberately left single-replica is named as such rather than implied to be redundant. The swap cost recorded on the map's risk list is unchanged by this decision, and it is the reason the line is defensible: every self-hosted component is between half a day and thirty days to replace, which is what makes self-hosting a choice rather than a trap. Finally, because the topology buys nodes rather than services, the cost model is tractable: the only fixed line item that cannot be driven to zero is the EKS control plane, which is what makes the free-to-run analysis in the cloud architecture a short argument instead of a long one.
